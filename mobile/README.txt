Mintygreen Charges Mobile PWA

Upload this entire folder into your GitHub repository as:

/mobile/

Files:
- mobile/index.html
- mobile/manifest.json
- mobile/sw.js
- mobile/icons/icon-192.png
- mobile/icons/icon-512.png
- mobile/icons/apple-touch-icon.png

After GitHub Pages publishes it, open:
https://minty-green.github.io/Charges/mobile/

The app uses the same Supabase project, staff accounts, residents, items,
charge_entries and billing-cycle locks as the main Charges website.

Android/Chrome:
Use the Install Mintygreen Charges button when offered, or browser menu > Install app.

iPhone/Safari:
Share > Add to Home Screen.

Do not add any secret/service-role keys to these files.
